# pulserate

Pulse timestamps and rate durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/pulserate/

## Install / run

```bash
git clone https://github.com/theworker02/pulserate.git
cd pulserate
node src/cli.js
node --test
```
